# Synthetic Cardiometabolic Evidence Framework

## Section 1 — Prototype rule framework

This fictional guideline exists solely for the hackathon demonstration. The application uses transparent rules, not a clinical prediction model. A documented hypertension condition, elevated LDL, or elevated A1c can be displayed as separate evidence items for a reviewer.

## Section 2 — Interpretation boundaries

Evidence items in this prototype are prompts for review. They are not diagnoses, treatment recommendations, or estimates of real-world event probability.

## Section 3 — Traceability

Every displayed factor should be traceable to a structured synthetic record or an explicitly labeled fictional document section. The copilot should distinguish a recorded fact from an inference.
